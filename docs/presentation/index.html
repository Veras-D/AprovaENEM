Engenharia de Software

Arquitetura de Microsserviços e Segurança de Perímetro

Padrões corporativos de resiliência, isolamento de rede Zero-Trust e mensageria assíncrona.

07 / 10

🛡️ Política Zero Host Port Exposure & BFF Gateway

Apenas as portas públicas 80 e 443 do Nginx Reverse Proxy são expostas ao host. Todo o tráfego interno dos microsserviços, bancos de dados PostgreSQL e RabbitMQ trafega estritamente dentro de uma rede privada isolada.

⚡ Java 21 LTS, Spring Boot 3.3 & Hexagonal Core

Separação estrita entre o núcleo de domínio puro (sem dependência de frameworks) e os adaptadores de infraestrutura (Spring Data JPA, Redis, RabbitMQ, Web REST).

📨 Transactional Outbox Pattern com RabbitMQ

Eliminação do problema de escrita dupla (dual-write) gravando eventos de domínio atomicamente no PostgreSQL e despachando de forma garantida para o broker RabbitMQ.

🔄 Orquestração Resiliente & Autoheal

Topologia de 14 contêineres Docker Compose com reinicialização automática, healthchecks Spring Boot Actuator e daemon de auto-recuperação sem sobrecarga de Kubernetes.

Tratamento ético e transparente de dados de estudantes conforme a Lei nº 13.709/2018.

🧒 Proteção Integral do Adolescente (Art. 14 da LGPD)

Todo o tratamento de dados é realizado no melhor interesse do estudante secundarista. Os dados nunca são vendidos, comercializados ou compartilhados com faculdades privadas, bancos ou redes de publicidade direcionada.

📦 Direito à Portabilidade de Dados (Art. 18, V)

Endpoint de autoatendimento (GET /api/v1/auth/export) que gera um download instantâneo em formato JSON estruturado contendo todo o histórico de simulados, metas e registros do aluno.

🗑️ Direito à Eliminação Definitiva (Art. 18, VI)

Exclusão irreversível com dupla confirmação e desafio de texto (DELETE /api/v1/auth/me). Elimina todas as credenciais do auth_db enquanto desvincula tentativas históricas no exam_db (user_id = NULL), preservando as estatísticas da TRI sem manter dados pessoais.
